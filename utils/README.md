# utils

Это твоя библиотека чтения конфигов. Она сохранена отдельно от газового решателя.

## Что здесь лежит

| Файл | Зачем нужен |
| --- | --- |
| `toml.hpp` | Читает сам синтаксис TOML |
| `toml-processor.hpp` и `toml-processor.cpp` | Проверяют поля волнового конфига версии 1 и собирают объект Config |
| `math-expression.cpp` | Подготавливает и вычисляет формулы |
| `exprtk.hpp` | Библиотека, которая считает эти формулы |
| `exprtk-LICENSE.txt` | Лицензия ExprTk |
| `test.toml` | Пример волнового конфига |
| `tests/toml-processor-test.cpp` | Проверки ридера и формул |

## Как прочитать конфиг в C++

```cpp
#include "toml-processor.hpp"

auto config = tomlprocessor::ConfigProcessor::parse_file("utils/test.toml");
```

Путь к самому TOML задаётся относительно места запуска программы. Пути внутри TOML ридер считает относительно папки этого TOML.

При подключении через CMake используй цель `config-reader`. Она собирает оба файла: `toml-processor.cpp` и `math-expression.cpp`.

## Как это связано с текущим CLI

- `solver-cli` запускает газовые задачи из `configs/toro_*.toml`. Это формат версии 2; его читает `EulerConfig`.
- `ConfigProcessor` из этой папки читает волновой формат версии 1 и использует ExprTk для выражений.
- Прочитать волновой конфиг можно. Сам волновой расчёт пока не написан.

`test.toml` — пример для ридера, а не готовый запуск через газовый CLI. Описание табличных данных или плагина ридер может прочитать, но загрузки CSV и запуска плагинов в нём нет.
