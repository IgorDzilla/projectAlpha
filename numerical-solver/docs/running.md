# Запуск точного решения одной задачи Римана

Все команды выполняются из каталога `project Alpha`.

## Собрать и запустить

Нужны CMake и компилятор C++17:

```sh
cmake -S numerical-solver -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target solver-cli
./build/solver-cli configs/toro_1.toml --output-dir results/sod-1
```

`--output-dir` задаёт новый или пустой каталог результата. Без него каталог
берётся из `[output].directory` в TOML относительно папки самого TOML.
Изменение TOML не требует пересборки.

Программа решает исходный разрыв **один раз**. При `domain.t = [t0, tout]`
она сохраняет начальный профиль при `t0` и точный профиль при `tout`.
Для второй выборки используется автомодельная координата
`(x - initials.discontinuity) / (tout - t0)`. Если `tout == t0`,
сохраняется только начальный профиль.

## Результат

- `solution.csv`: строки `time,point,x` и выбранные поля газа. `point` — номер
  точки отбора, а значения относятся к координате `x`, не являются средними
  по ячейкам. Время здесь обозначает момент просмотра решения, а не шаг схемы.
- `run.txt`: параметры задачи, `p_star`, `u_star`, плотности звёздных состояний,
  типы и скорости волн, число итераций поиска давления и `status=complete`.

При ошибке программа возвращает ненулевой код. Вакуумное решение пока не
поддерживается. Уже заполненный каталог результата не перезаписывается.

## Графики

Нужны Python, NumPy и Matplotlib:

```sh
python3 plot_toro.py results/sod-1
```

В `results/sod-1/plots/` появятся профиль, диаграмма состояний на плоскости
`p–u`, PDF и короткий отчёт. Линии на профиле показывают найденные положения
ударных волн, границ вееров разрежения и контакта.

## Параметры TOML

Формат этих конфигов имеет `config_version = 3`.

| Поле | Значение |
| --- | --- |
| `parameters.gamma` | Показатель адиабаты идеального газа, больше 1 |
| `domain.x` | Интервал координат для отображения профиля |
| `domain.t` | Начальный момент и момент просмотра, `tout >= t0` |
| `grid.points` | Число точек отбора профиля, положительное целое |
| `initials.discontinuity` | Координата исходного разрыва внутри `domain.x` |
| `initials.left`, `initials.right` | Плотность, скорость и давление с каждой стороны |
| `solver.method` | Только `exact_riemann` |
| `solver.exact` | Допуски и предел итераций поиска звёздного давления |
| `output.directory` | Каталог результата |
| `output.fields` | Поля CSV: `density`, `momentum`, `energy`, `velocity`, `pressure` |

Плотность и давление должны быть положительными. `grid.points` задаёт только
выборку для файла и графика; изменение этого числа не меняет найденные волны.
Настроек CFL, граничных условий, потоков между ячейками и шага по времени в
этом формате нет.

## Все пять конфигов Торо

Для каждого запуска нужен отдельный каталог:

```sh
for i in 1 2 3 4 5; do
  ./build/solver-cli "configs/toro_${i}.toml" --output-dir "results/toro-run-1/toro_${i}" || break
done
python3 plot_toro.py results/toro-run-1
```

Для повторного запуска замени `toro-run-1` на другое имя. Отдельная цель
`toro-plots` дополнительно сверяет параметры волн с табличными эталонами Торо
и строит расширенный отчёт:

```sh
cmake -S numerical-solver -B build -DBUILD_TESTING=ON
cmake --build build --target toro-plots
```
