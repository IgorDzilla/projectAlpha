# Запуск расчётов Эйлера в 1D

Рабочая последовательная цепочка: TOML v2 → EulerConfig → RiemannProblem1D → FiniteVolume/GodunovFlux → ExplicitEuler/ExplicitSolver → CSV. Поддержаны пять входных файлов `toro_1.toml`–`toro_5.toml` в соседнем [configs](../../configs).

## Сборка и один запуск

Из каталога `numerical-solver`:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF
cmake --build build --target solver-cli
./build/solver-cli ../configs/toro_1.toml
```

Без дополнительных аргументов результат первого случая попадёт в `../configs/results/toro_1`. Все пути из TOML отсчитываются **от каталога TOML**, независимо от текущего рабочего каталога.

Для другого каталога результата:

```sh
./build/solver-cli ../configs/toro_1.toml --output-dir /tmp/sod-new-run
./build/solver-cli --help
```

Путь `--output-dir` отсчитывается от текущего рабочего каталога. Каталог результата должен быть новым или пустым: повторный запуск не затирает предыдущие данные. Если `[output]` отсутствует, файлы не создаются; явный `--output-dir` включает вывод всех пяти полей с сохранением каждого шага.

Все пять случаев (после уже выполненного запуска используйте новые каталоги):

```sh
for i in 1 2 3 4 5; do
  ./build/solver-cli "../configs/toro_${i}.toml" --output-dir "/tmp/toro-new-run-${i}"
done
```

## Графики результатов

Для plot_toro.py нужны NumPy и Matplotlib. Из numerical-solver:

```sh
python3 ../plot_toro.py ../configs/results
```

Для одного случая или другого каталога рисунков:

```sh
python3 ../plot_toro.py ../configs/results/toro_1 --output-dir /tmp/sod-plots
```

Скрипт читает solution.csv и run.txt. По умолчанию создаёт подкаталог plots внутри переданного пути: PNG по каждому случаю, общий toro_figures.pdf, REPORT.md и toro_summary.csv с минимумами/максимумами конечного слоя. Повторный запуск перезаписывает одноимённые графики и отчёты; исходные CSV и run.txt не меняются.

Профили показывают начальные и конечные численные значения; x–t использует фактические неравномерные моменты сохранения. Диаграмма p–u показывает состояния ячеек, окрашенные по координате, а не точные волновые кривые. Эталон и ошибки относительно него не вычисляются.

Скрипт проверяет завершение расчёта, количество и времена слоёв, уникальность номеров ячеек, сетку и физическую допустимость данных. Порядок строк CSV не важен. Недостающие скорость/давление восстанавливаются из консервативных величин, если они присутствуют. Для сокращённого output.fields строятся только доступные величины; p–u пропускается без давления или скорости. Один момент времени не выдаётся за эволюцию: вместо x–t выводится пояснение.
